# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».


## Способ подключения

Стили подключены локально. Все кастомные стили, сетки и компоненты написаны вручную в едином файле `css/custom.css`, который подключен ко всем HTML-страницам проекта.

## Реализованные компоненты (собственная разработка)

В файле `custom.css` с нуля реализованы следующие компоненты:
- `sticky-фильтры` (блок с фильтрами в каталоге, который прилипает при прокрутке);
- `навигационное меню` (адаптивное, с активными состояниями);
- `карточка товара` (сетка товаров с рамками, тенями и эффектами при наведении);
- `таблица сравнения` (с кастомным оформлением заголовков и строк);
- `аккордеон FAQ` (реализован на нативных HTML-тегах `<details>` и `<summary>` с кастомными иконками);
- `формы` (поля ввода, селекты, чекбоксы с кастомной стилизацией);
- `кнопки` (модификации primary и secondary, состояния hover и focus-visible);
- `карточки отзывов` (с выводом картинки товара, названия, оценки в виде звезд и даты);
- `хлебные крошки` (breadcrumbs);
- `модальное окно` (диалоговое окно для быстрой заявки).
